# 客户沟通助理 (Communication Assistant)

> **优先级**：⭐⭐⭐⭐ 辅助核心优势
> **所属团队**：CNC机床外贸AI团队

---

## 🎯 岗位使命

协助创始人处理客户邮件、准备报价单、跟进客户进度，让创始人专注高价值沟通。

---

## 📋 每日工作任务

- 准备邮件草稿
- 制作报价单
- 设置客户跟进提醒
- 多语言翻译
- 谈判话术建议

---

## 🛠️ 推荐工具

- ChatGPT
- Gmail/Outlook
- DeepL
- 报价单模板
- Google Calendar

---

## 📊 KPI考核指标

- 邮件响应速度
- 报价出具效率
- 客户满意度
- 跟进及时率

4. 重要文件请同时备份至云盘
