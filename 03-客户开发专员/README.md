> **优先级**：⭐⭐⭐⭐⭐ 核心业务

## 🎯 岗位使命

- 搜索目标市场潜在客户
- 整理客户数据库
- 撰写并发送个性化开发信
- LinkedIn社交开发
- 跟进潜在客户回复

---

## 🛠️ 推荐工具

- LinkedIn Sales Navigator
- Apollo.io
- Hunter.io
- ChatGPT
- Google Sheets

## 📊 KPI考核指标

- 开发信回复率
- 有效询盘数
- 客户数据库规模
