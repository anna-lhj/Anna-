# 订单跟单助理 (Order Follow-up)

> **优先级**：⭐⭐⭐⭐ 重要
> **所属团队**：CNC机床外贸AI团队

---

## 🎯 岗位使命

跟踪从打样到发货的全流程，协调供应商与货代，确保订单准时交付。

---

## 📋 每日工作任务

- 更新订单状态
- 协调供应商排产
- 准备发货文件
- 物流跟踪与更新
- 客户交期通知

---

## 🛠️ 推荐工具

- Google Sheets/Excel
- ChatGPT
- 物流查询工具
- ERP系统
- 邮件

---

## 📊 KPI考核指标

- 订单准时交付率
- 客户投诉率
- 生产进度准确率
- 物流异常处理速度

---

## 📁 工作成果目录

| 文件夹 | 用途 |
|-------|------|
| 订单跟踪 | 存放订单跟踪相关内容 |
| 生产进度 | 存放生产进度相关内容 |
| 物流文件 | 存放物流文件相关内容 |
| 交期通知 | 存放交期通知相关内容 |
| 质量记录 | 存放质量记录相关内容 |

---

## 📌 预期输出成果

- 订单进度看板
- 打样/生产进度报告
- 物流单据整理
- 客户交期通知

---

## ✅ 使用说明

1. 将工作成果保存到对应子文件夹
2. 文件命名规范：日期_内容主题_版本号（如：20261016_产品视频_V1）
3. 每周五整理本周工作成果并更新进度
4. 重要文件请同时备份至云盘
