# 市场分析专员 (Market Analyst)

> **优先级**：⭐⭐⭐ 支持
> **所属团队**：CNC机床外贸AI团队

---

## 🎯 岗位使命

持续跟踪CNC机床行业动态、竞品情况、目标市场政策，为业务决策提供数据支持。

---

## 📋 每日工作任务

- 竞品价格监控
- 目标市场政策研究
- 行业新闻追踪
- 数据收集与整理
- 分析报告撰写

---

## 🛠️ 推荐工具

- ChatGPT
- Google Trends
- 海关数据
- 行业报告
- Statista

---

## 📊 KPI考核指标

- 报告质量与及时性
- 市场洞察价值
- 竞品信息覆盖率
- 数据准确率
